# 🎬 Netflix Content Analytics Dashboard

An interactive **Power BI dashboard** built to analyze Netflix's content library using data visualization, DAX, and Power Query. This project transforms raw Netflix data into meaningful insights through an intuitive and visually appealing dashboard inspired by the Netflix theme.

---

## 📌 Project Overview

The Netflix Content Analytics Dashboard provides a comprehensive analysis of Netflix's movies and TV shows. It helps users explore content distribution across countries, genres, ratings, and release trends using interactive visualizations and slicers.
